Manage every Docker server from one console.

Kowan is the self-hosted Docker management platform for teams and home labs: deploy, monitor and fix containers and Compose stacks on all your servers, in the cloud, in the office or behind a home router.

Up and running in a minute

All you need is a server with Docker. Kowan works out of the box; to add more servers later, set KOWAN_EXTERNAL_URL to the address they will use to reach it.

$ docker run -d --name kowan --restart unless-stopped \
    -p 5081:5081 \
    -v kowan-data:/data \
    -v /var/run/docker.sock:/var/run/docker.sock \
    ghcr.io/kowan-lab/kowan:latest
docker-compose.yml
services:
  server:
    image: ghcr.io/kowan-lab/kowan:latest
    ports:
      - "5081:5081"
    volumes:
      - kowan-data:/data
      - /var/run/docker.sock:/var/run/docker.sock
    restart: unless-stopped

volumes:
  kowan-data:
$ docker compose up -d

  1. Start Kowan

    Run Kowan with docker run or Docker Compose. All its data lives in the kowan-data volume, the only thing you need to back up.

  2. Create your account

    Open http://localhost:5081 and create the admin account with the one-time setup code shown by docker logs kowan. The server Kowan runs on is ready to manage.

  3. Add your other servers

    In Hosts → Add host, copy the one-line command Kowan gives you and run it on each server you want to manage.

Frequently asked questions

What is Kowan?

Kowan is a self-hosted Docker management platform. From one web console you manage containers, Docker Compose stacks, images, volumes and networks on all your servers, deploy applications, and monitor their health, logs and resources.

Is Kowan an alternative to Portainer?

Yes. Kowan covers the container management Portainer users expect and adds Git-based deployments with revisions and rollback, preview environments, uptime monitoring, log search and resource history. You can import your existing Portainer stacks.

Can I manage servers behind NAT or a firewall?

Yes. The Kowan agent connects out to your Kowan server, so servers in a home lab, an office or a private network need no open ports. Servers on a reachable network can also be connected directly.

Does Kowan support Docker Compose?

Yes. Deploy Compose stacks from the built-in editor, a template or a Git repository, and Kowan checks each file for port conflicts, clashing names and missing variables before it runs. Compose projects that are already running are picked up automatically.

Where is my data stored?

On your own server, in a single Docker volume. Kowan needs no cloud account or external database, and your infrastructure data never leaves it. The only outbound request is an optional check for new Kowan versions.

Can my team use Kowan?

Yes. Roles, teams and per-resource permissions decide who can view or change each server and application, with single sign-on through OpenID Connect or GitHub and an audit log of every change.

Which servers can run Kowan?

Any Linux server with Docker, on x86-64 (amd64) or ARM64 processors, in the cloud or on premises. Kowan runs as one container, with a small agent on each additional server.

How much does Kowan cost?

Nothing. Kowan is free and open source, with no paid plan and no limit on servers, containers or users.
