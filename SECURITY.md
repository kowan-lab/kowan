# Security policy

Kowan controls Docker hosts, so a vulnerability can mean root access to a machine. Please report it privately.

## Reporting a vulnerability

Use GitHub's private reporting: **Security → Report a vulnerability** on the [repository page](https://github.com/kowan-lab/kowan/security/advisories/new).

Please include the affected version, how to reproduce the issue and its impact. You will get an acknowledgement within a few days. A fix is prepared in a private advisory and released together with the disclosure.

## Supported versions

Kowan is pre-1.0. Security fixes go into the latest release only.
