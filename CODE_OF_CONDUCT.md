# Code of conduct

Kowan follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussions about the work. Harassment of any kind is not tolerated.

Report unacceptable behaviour privately to the maintainers through a [private security advisory](https://github.com/kowan-lab/kowan/security/advisories/new) or by contacting a maintainer directly. Reports are handled confidentially.
